## Vault conventions

| Term | Meaning |
|---|---|
| Zettel | Atomic note, one idea per file, named `YYYYMMDDHHMM - <topic>.md` |
| Topic note / Hub | Non-timestamped note like `probability.md` that collects and links zettels |
| Daily note | One file per day in `000 - daily notes/`, named `YYYY-MM-DD.md` |
